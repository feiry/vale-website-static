Website Update Requests — PT Vale Indonesia static site
========================================================

This is where the COMMs team requests updates to www.valeindonesia.com.
You author the content; GDI reviews and publishes it. You never need Azure access.

HOW IT WORKS
  1. Copy a template from _Templates/ into a NEW folder inside 1-Submitted/.
     Name the folder:  YYYY-MM-DD_<type>_<short-name>
     e.g.  2026-09-10_news_pkb-negotiation
     (type = news | document | page-edit | new-page)
  2. Fill in the template (save it as request.md) and add every image/PDF
     you reference into the SAME folder.
  3. That's it — GDI takes it from 1-Submitted/.

FOLDERS (status = which folder your request sits in)
  _Templates/       Blank templates + the full how-to guide. COPY from here.
  1-Submitted/      You drop your request folder here.
  2-In-Progress/    GDI moves it here while working on it.
  3-Done-Deployed/  GDI moves it here once it's live (with the live links).

Full instructions: _Templates/How-to-request-a-website-update.md
